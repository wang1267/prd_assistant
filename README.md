# 需求文档工作台

> 本地优先 · 单文件 · 零网络 —— AI 驱动的 PRD 写作与健康度体检工具（人人可用，尤其适合用 AI 构建产品的开发者）

面向所有人（尤其是用 AI 构建产品的开发者与产品人）的 PRD 写作与健康度体检工具。先把模糊想法写成清晰的 PRD，再交给 AI 高效落地执行；通过 AI + 12 项指标自动评估 PRD 的完整性、一致性与可追溯性，帮助快速发现文档缺口、提升质量。

## 核心特性

### AI 能力

- **AI 体检评分** — AI 对 PRD 全文进行健康度评分，支持分块评分（chunked）、热力图实时进度、下钻 AI 诊断、ai-hit 红点标记
- **AI 内容优化** — AI 逐节优化 PRD 内容，支持多轮迭代（可配 maxRounds）、目标分数（targetScore）、安全模式（safe）、差异预览与应用
- **AI 对话助手** — 右下角浮动面板（流式对话，产品经理人设），支持深度思考过程实时展示与折叠翻阅；可执行操作（新建项目 / 编辑段落 / 重命名章节 / 应用模板等）
- **多角色评审** — 产品 / 研发 / 测试 / 设计 / 项目经理五视角评审，逐角色流式输出评审意见，支持评审历史复看（最多 20 条）与跨项目评审
- **深度思考** — 推理过程（reasoning_content）以可折叠思考块实时展示：流式时自动展开、自动下翻到最新内容，完成后可收起翻阅
- **AI 章节生成** — AI 根据框架自动生成章节内容、风格指南、类型 schema
- **AI 审查** — 独立审查模型（reviewModel），AI 审查 PRD 并给出问题引用 + 改进建议
- **AI 对齐与差异** — AI 对齐内容、生成 diff、逐项应用/撤销/预览
- **AI 版本管理** — 优化前后自动创建版本快照，支持回滚
- **AI 表格处理** — AI 解析 CSV/Markdown 表格、增删行列、缩放、导入
- **AI 风险管控** — 高风险操作确认、操作风险评估、变更验证
- **AI 思考球** — 纯 CSS 零依赖动画（轨道发光粒子 + 扫描环），显示 AI 工作状态

### 基础功能

- **健康度体检** — 12 项指标自动评估完整性 / 一致性 / 可追溯性
- **总览视图** — 指标卡 + 缺口清单 + 文档章节卡片 + AI 总评
- **富文本卡片编辑** — 章节内支持卡片式内容编辑（新增/删除/拖拽）
- **评论批注** — 章节级评论批注，团队协作留痕
- **图片 / 表格插入** — 富文本区域支持插入图片和表格
- **手动改色** — 人工覆盖引擎判定（红/黄/绿），记录改色原因
- **复制健康度报告** — 一键复制健康度摘要，方便粘贴汇报
- **多格式导入** — Markdown / Word / 粘贴文本 / 备份恢复
- **多格式导出** — MD / Word / 备份文件 / 框架导出
- **项目管理** — 多项目 + 分组管理，快速切换
- **框架编辑增强** — 自定义 PRD 框架结构（增删/排序/类型/权重）
- **本地优先** — 数据存储在浏览器 localStorage，零网络零依赖（AI 调用需配置 API Key）

## AI 模型配置

在「设置 → AI」中配置：

| 配置项 | 说明 |
|--------|------|
| Provider | API 提供商（OpenAI 兼容） |
| Base URL | API 地址 |
| Model | 主模型（默认 `deepseek-chat`） |
| Review Model | 审查模型（可独立配置） |
| API Key | 密钥（本地存储，不上传） |
| Target Score | 目标分数（50-100） |
| Max Rounds | 最大优化轮次（1-5） |
| Web Search | 是否启用联网搜索 |

**已测试兼容**：DeepSeek（deepseek-chat）、智谱 GLM（glm-4.5-air）、OpenAI 兼容 API

## 设计语言

浅色编辑感，参考 Notion / Aesop 官网风格。

| 维度 | 规范 |
|------|------|
| 背景 | 暖白纸感 `#faf9f7` |
| 文字 | 深墨 `#1c1b19` |
| 主色 | 深蓝绿 `#1f3a45` |
| 状态色 | 莫兰迪：砖红 `#a8554c` / 芥末黄 `#b08a3e` / 灰绿 `#6b8a6e` |
| 标题字体 | Noto Serif SC（思源宋体）|
| 正文字体 | 系统无衬线 |
| 数字字体 | JetBrains Mono（等宽 tabular）|
| 圆角 | 12px 为主 |
| 阴影 | 极淡 `0 1px 2px rgba(28,27,25,.04)` |
| 图标 | 统一线性描边 SVG（`ICONS` 全局常量），界面不使用 emoji |

## 技术栈

纯原生 HTML + CSS + Vanilla JavaScript，单文件，无框架无构建工具，双击即可打开。AI 功能通过 OpenAI 兼容 API 调用，支持流式输出。

## 快速开始

1. 下载 `PRD智能看板.html`
2. 双击用浏览器打开
3. 点击顶部「导入▼」导入 PRD 文档，或「加载示例」体验
4. 在「设置 → AI」配置 API Key 后，使用 AI 体检 / 优化 / 对话功能
