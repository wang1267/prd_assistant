欢迎使用 · PRD 健康度驾驶舱

这是什么

一个本地优先、单文件、零网络的 PRD 健康度驾驶舱：你导入或撰写的 PRD 会经规则引擎逐节体检（红黄绿），顶部出健康度面板，缺口自动列成可跳转清单。

你的 PRD 永远不离开这台电脑——不上云、不收集、不联网。

支持导入的格式

  • 文件：.md / .markdown / .txt / .html / .docx（Word 自动识别），或粘贴文本
  • 分节：按 Markdown 标题（#~######）映射到框架节
  • 功能点行：名称｜描述｜优先级｜状态
  • 验收：- [ ] 文本
  • 用户故事：作为X，我希望Y，以便Z
